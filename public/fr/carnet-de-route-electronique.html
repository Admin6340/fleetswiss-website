Comment ça marche

Comment fonctionne le carnet de route électronique avec code QR

  1. 1

    Réserver

    Les collaborateurs choisissent le véhicule de pool disponible et réservent la période souhaitée.

  2. 2

    Scanner le code QR

    Scanner le code QR du véhicule avec le smartphone. FleetSwiss s'ouvre directement dans le navigateur – aucune installation d'application séparée n'est nécessaire.

  3. 3

    Démarrer le trajet

    Saisir le kilométrage et le motif du trajet, puis démarrer le trajet.

  4. 4

    Terminer le trajet

    Saisir le kilométrage final. FleetSwiss documente de manière traçable le conducteur, le véhicule, l'heure et le trajet.

FAQ

Questions fréquentes sur le carnet de route électronique

Qu'est-ce qu'un carnet de route électronique ?

Un carnet de route électronique ou numérique remplace le carnet de route papier dans le véhicule. Les trajets sont saisis numériquement avec le conducteur, le véhicule, l'heure, le kilométrage et le motif du trajet, et restent documentés de manière traçable.

Comment fonctionne le carnet de route électronique FleetSwiss ?

Les collaborateurs réservent un véhicule de pool disponible, scannent le code QR du véhicule, saisissent le kilométrage et le motif du trajet, puis démarrent le trajet. Après le trajet, le kilométrage final est saisi. FleetSwiss documente le conducteur, le véhicule, l'heure et le trajet.

Ai-je besoin d'une application ?

Non. FleetSwiss Digital Logbook ne nécessite aucune installation d'application séparée. Le code QR sur le véhicule peut être scanné avec le smartphone et ouvre FleetSwiss directement dans le navigateur.

Comment fonctionne le code QR sur le véhicule ?

Un code QR est apposé sur le véhicule. Les conducteurs le scannent avec leur smartphone, FleetSwiss s'ouvre dans le navigateur et, après la connexion, ils accèdent directement au bon véhicule pour démarrer ou terminer le trajet.

Plusieurs collaborateurs peuvent-ils utiliser le même véhicule de pool ?

Oui. Les véhicules de pool sont attribués dans le temps via la réservation. Chaque trajet est documenté avec le conducteur, l'heure et le kilométrage.

Les véhicules de pool peuvent-ils être réservés en ligne ?

Oui. Les collaborateurs voient la disponibilité et réservent le véhicule souhaité pour la période nécessaire.

Peut-on aussi réserver des remorques et d'autres ressources ?

Oui. Outre les véhicules de pool, il est possible de gérer des remorques, des véhicules de remplacement et d'autres ressources de l'entreprise. Pour les ressources non soumises à l'obligation de carnet de route, seule la réservation peut être utilisée.

Plusieurs entreprises peuvent-elles utiliser les mêmes véhicules de pool ?

Les ressources de pool partagées peuvent, avec l'autorisation et la configuration correspondantes, être utilisées aussi entre organisations. Il n'existe pas d'accès automatique au sein d'un groupe d'entreprises.

Les véhicules sont-ils surveillés en permanence par GPS ?

Non. La fonction carnet de route ne surveille pas les véhicules en permanence. Si elle est activée, une localisation ponctuelle peut être enregistrée au début et à la fin d'un trajet.

Combien coûte le carnet de route électronique ?

FleetSwiss Digital Logbook est disponible dès CHF 99.– par mois (Starter, jusqu'à 5 véhicules avec carnet de route, CHF 1'188.– par an). La facturation est annuelle et payable d'avance ; tous les prix s'entendent hors TVA. En plus, des frais de mise en place uniques sont facturés. FleetSwiss en communique le montant après réception de la commande et avant l'exécution de la mise en place payante.

FleetSwiss peut-il être étendu ultérieurement à une gestion de flotte complète ?

Oui. Vous pouvez commencer avec le carnet de route électronique et, si nécessaire, passer à FleetSwiss Full Fleet Software ou ajouter le FleetSwiss Fleet Management Service. Nous vous établissons pour cela une offre individuelle.
